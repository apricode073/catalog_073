# Cataloguer

Система управления каталогом учебных аудиторий.

## Установка

```bash
python -m pip install -e .
```

## Использование

Демонстрационный запуск:

```bash
python -m catalog
```

## Предметная модель

Аудитория представлена неизменяемым dataclass `Classroom`.

| Поле | Тип | Ограничение |
|---|---|---|
| item_id | str | Непустая строка, уникальная в пределах каталога |
| name | str | Непустая строка |
| category | str | Непустая строка |
| year | int | От 1 до текущего года |
| capacity | int | Положительное целое число |
| building | str | Непустая строка |

## Особенности реализации

- Итерация в порядке добавления объектов.
- Повторное добавление удалённого объекта помещает его в конец каталога.
- Поиск по категории учитывает регистр.
- Поиск по названию выполняется по подстроке без учёта регистра.
- Методы поиска возвращают новые списки.
- При возникновении ошибки JSON состояние каталога остаётся неизменным.

### Индекс по категории

Дополнительный словарь сопоставляет категории с ID аудиторий. Индекс обновляется согласованно с основным хранилищем.

### Undo

Метод `undo()` отменяет последнюю успешную операцию добавления или удаления. При восстановлении удалённого объекта сохраняется его первоначальная позиция.

Повторная отмена без новой операции запрещена.

### Read-only view

Метод `view()` возвращает актуальное представление каталога, без публичных методов изменения данных.

### Миграция JSON

Поддерживаются две версии формата, с хранением под разными ключами:

- v1 — `items`;
- v2 — `classrooms`.

При сохранении используется версия 2.

### История версий

История реализована в виде журнала операций без копирования каталога. Она хранится в оперативной памяти.

Свойство `version` возвращает номер текущей версии, а метод `get_version(version)` — состояние указанной версии.

Успешные операции добавления, удаления и отмены создают новые версии каталога.

Загрузка JSON начинает новую историю с номера 0, если успешна.

## Алгоритмическая сложность

| Операция | Средняя сложность |
|---|---|
| Добавление | O(1) (амортизированно) |
| Поиск по ID | O(1) |
| Удаление | O(n) |
| Поиск по категории | O(k) |
| Поиск по названию | O(n) |
| Проверка наличия ID | O(1) |
| Получение размера | O(1) |

n — количество объектов в каталоге.

k — количество объектов в категории.
